# MONJU MVP 要件サマリー

原資料: 「MONJU MVP / 実装要件定義書 v1.0」

## 目的

少人数チームが物理的に集まったことを位置情報から検知し、`位置共有 → 集合検知 → 通知 → 録音 → 文字起こし`をつなげます。地図や移動履歴を持たず、位置情報は集合判定だけに使います。

## MVPフロー

1. Googleログイン
2. グループ作成または10分・1回限りのQR招待で参加
3. ユーザーが位置共有をON
4. サーバーが最新位置、5分の鮮度、精度、中心点からの距離を評価
5. 必要人数が50m以内に60秒間集まるとGATHERED
6. 全対象者へPushし、最初に操作した1人だけが録音担当をclaim
7. M4A/AACを端末へ最大1時間録音
8. 停止直後に文字起こしし、音声とテキストを端末内保存

## 状態と初期値

| 項目 | 初期値 |
| --- | --- |
| 集合人数 | 2人以上、グループ設定 |
| 集合半径 | 50m |
| 集合継続 | 60秒 |
| GPS瞬断猶予 | 5秒 |
| 解散判定 | 10分 |
| 位置鮮度 | 5分 |
| 再通知 | 30分 |
| 録音上限 | 1時間 |

状態は`NOT_GATHERED`、`CANDIDATE`、`GATHERED`、`LEAVING`です。一瞬の距離逸脱ではcandidateを即時リセットせず、解散後に再集合すれば新規通知します。

## データ境界

- サーバーに保存する位置は各ユーザーの最新1件だけ
- 位置履歴、集合履歴、移動ルートを保存しない
- 緯度経度を他ユーザーへ返さない
- 音声と文字起こしをサーバーへ送らない
- QRトークンは平文保存せず、期限10分、単回利用
- Token、座標、秘密情報をログへ出さない

## 必須E2E

1. 3人の通常集合 → 60秒 → Push
2. 数秒だけ半径外へ出るGPSブレ
3. accuracy 80mから高精度へ切り替え
4. 5分超の古い位置を除外
5. 集合後に1人離れ10分で解散
6. 解散後の再集合と再通知
7. 集合継続・録音なしで30分再通知
8. 複数人同時タップで録音担当1人だけ成功

## MVP対象外

地図、位置/集合履歴、クラウド音声保存、AI要約、話者分離、チャット、SNS、リーダー変更、完全自動バックグラウンド録音は対象外です。

詳細な実装境界と現在の差分は[実装状況](./IMPLEMENTATION_STATUS.md)を参照してください。
